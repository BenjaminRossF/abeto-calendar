# Label

## Propósito

Etiqueta accesible que asocia texto con un control mediante htmlFor.

## Props

Acepta las props de label HTML, incluidas htmlFor, className y los manejadores de eventos.

## Uso

~~~tsx
<Label htmlFor="name">Nombre</Label>
<Input id="name" />
~~~

Para formularios nuevos, FieldLabel compone este componente dentro de Field.
